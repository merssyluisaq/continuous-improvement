¿Qué es la Curva OC?

La curva operativa (OC curve)

Para un plan de muestreo (tamaño de muestra n, número de aceptación c), la curva OC muestra la probabilidad de aceptar un lote (Pa) frente a su % real de defectuosos (p). Su forma revela qué tan bien el plan separa los lotes buenos de los malos — y los dos riesgos que conlleva: rechazar lotes buenos (α) y aceptar lotes malos (β).

Uso en la vida real: Antes de firmar un acuerdo de inspección, el proveedor y el comprador usan la curva OC para verificar que el plan sea justo para ambos. Ejemplo: una fábrica inspecciona 60 de cada 1,000 silenciadores y acepta el lote si hay ≤ 1 defectuoso — la curva muestra con qué frecuencia se devuelven lotes buenos y se cuelan los malos.
Los dos riesgos de todo plan de muestreo
Riesgo Alfa (α) — Productor / Vendedor

Rechazar un lote bueno

El lote cumple el AQL (Nivel de Calidad Aceptable — el máximo % de defectuosos que el comprador acepta como "bueno"), pero el muestreo lo rechaza. El proveedor asume las consecuencias: devoluciones, retrasos y pérdida de confianza.

Riesgo Beta (β) — Consumidor / Comprador

Aceptar un lote malo

El lote tiene calidad intolerable (LTPD — Porcentaje de Defectuosos Tolerable del Lote, el % de defectuosos que el comprador considera inaceptable), pero el muestreo lo aprueba. El comprador recibe productos defectuosos, con riesgo de fallas y quejas de clientes.

1. Si aumentas el tamaño de muestra n (manteniendo c igual), ¿qué pasa con el riesgo del productor α?
a) Aumenta — una muestra mayor encuentra más defectos y rechaza más lotes
b) Disminuye — la curva se vuelve más empinada y separa mejor lotes buenos de malos
c) Se mantiene igual — n solo afecta el costo de inspección
¡Correcto! Un n mayor hace la curva OC más empinada — se acerca a la forma ideal de "escalón". Tanto α como β disminuyen porque el plan distingue mejor lotes buenos de malos. Pruébalo en la herramienta: sube n y observa cómo bajan ambos riesgos.
2. El riesgo del consumidor β es igual a Pa evaluado en qué nivel de calidad?
a) AQL — el nivel de calidad aceptable
b) LTPD — el porcentaje de defectuosos tolerable del lote
c) El punto medio entre AQL y LTPD
¡Correcto! β = Pa(LTPD). Como un lote en el nivel LTPD se considera intolerable, quieres que Pa sea muy bajo ahí — ese valor bajo ES β. Idealmente β ≤ 10%, lo que significa que el plan rechaza al menos el 90% de lotes así de malos.
3. Inspeccionas una muestra y encuentras d = 3 defectuosos. El número de aceptación es c = 3. ¿Cuál es la decisión?
a) Aceptar el lote
b) Rechazar el lote
c) Inspeccionar todo el lote antes de decidir
¡Correcto! La regla es: aceptar si d ≤ c. Aquí d = 3 y c = 3, así que d ≤ c → aceptar. El lote pasa. Pruébalo en el recuadro de decisión de arriba: pon c = 3 y d = 3.
4. ¿Cuál es la única forma de eliminar completamente los riesgos α y β?
a) Poner un número de aceptación c muy grande
b) Usar un AQL muy pequeño (cercano a 0%)
c) Inspeccionar el 100% del lote
¡Correcto! Mientras uses muestreo, siempre habrá alguna probabilidad de una decisión equivocada — es estadísticamente inevitable. Solo la inspección al 100% elimina ambos riesgos por completo. La curva OC puede hacerse muy empinada con un n grande, pero nunca se vuelve un escalón perfecto con muestreo finito.
Sobre el cálculo

Esta herramienta calcula la probabilidad de aceptación de Poisson directamente con la fórmula Pa = Σ e−λ·λk/k! para k = 0 hasta c, donde λ = n × p. Es la misma fórmula detrás de la tabla de Poisson impresa de tu material del curso. La tabla impresa redondea valores y obliga a interpolar entre filas, lo que introduce un pequeño error de redondeo. Esta herramienta usa el valor exacto de λ, así que los resultados pueden diferir en décimas de porcentaje respecto a la tabla — ambos son correctos; la tabla es simplemente una aproximación redondeada.

Nota importante: Los riesgos α y β no son errores operativos — son inherentes a todo proceso de muestreo estadístico. La única forma de eliminarlos por completo es con inspección al 100%. Lo que podemos hacer es minimizarlos ajustando n y c. El riesgo del productor recomendado es ≤ 5% y el del consumidor ≤ 10%.
